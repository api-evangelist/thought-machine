# Thought Machine

> Thought Machine is a London-headquartered cloud-native core banking technology company founded in 2014 by Paul Taylor. It builds Vault Core — a universal product engine where every banking product is written as a developer-authored smart contract executed against a real-time ledger — and Vault Payments, a cloud-native payments processing platform that natively represents payments as ISO 20022 messages. Both are API-first, but the developer documentation and API reference are served behind a partner login; there is no public OpenAPI, MCP server, or agent card.

## APIs

- [Vault Core API](https://www.thoughtmachine.net/vault-core): Cloud-native core banking engine. REST Core API for external integrations, Posting API for financial movements against the real-time ledger, Kafka Streaming API for accounting/balance/customer events, Migration API for legacy core data loads, Contracts API for smart-contract functions. Base URLs are per-deployment (SaaS tenant or bank-hosted cluster) and are not published publicly.
- [Vault Payments API](https://www.thoughtmachine.net/vaultpayments): Cloud-native payments processing across card, instant (FedNow, UK New Payments Architecture, SEPA Instant), batch clearing and cross-border rails. RESTful APIs plus real-time streaming of payment, product, payment-instrument and configuration data. Dynamic account routing decouples payment instruments from funding sources.
